# [PT-BR] Versão Brasileira (Gold / Silver / Crystal)

Tradução para português do Brasil dos **diálogos** de *Pokémon Gold*, *Pokémon Silver* e *Pokémon LeafGreen* no formato de **mod para o gen1recomp**.

## Créditos

- **Tradu-Roms**: Tradução original de GSE para GBC, lançada no começo dos anos 2000 por R_Lopes e Night_Shadown;
- **Solid One**: Criação do mod, port inicial dos textos, e revisão;
- **LordSangreal**: Revisão e teste;

## Instalação

Coloque a pasta em:

```
%APPDATA%\pokemon-love2d\mods\gen2_gsc_pt-br_mod\
```

e abra o jogo. O mod é carregado por padrão (não é experimental). Gold, Silver ou Crystal precisam estar importados no launcher.
